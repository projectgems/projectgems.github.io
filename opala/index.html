O que o Opala faz

Tudo organizado no !menu, com uma frase explicando cada comando.

🎵Músicas e downloadsYouTube, TikTok, Spotify, SoundCloud e letras de música.
✨FigurinhasDe fotos e vídeos, brat, emojimix e figurinhas com texto.
🎮BrincadeirasJogo da velha, UNO, quiz, wordle, casal do dia e testes de %.
⚔️RPGCarteira, banco, empregos, pesca, mineração, pets e clãs.
🛡️Proteção do grupoAntilink, boas-vindas com cartão, advertências e moderadores.
🧰FerramentasLembretes, notas, tradutor, calculadora, QR code e voz.

Como instalar

Escolha onde ele vai morar. Na primeira vez, o Opala pergunta seu nome, seu número e o prefixo, e depois você conecta o número do bot.

📱 Termux (celular)

Bom para testar ou usar com o celular na tomada. Instale o Termux pelo F-Droid.

pkg install -y nodejs-lts git ffmpeg python
pip install -U yt-dlp
git clone https://github.com/ruan2311/opala.git
cd opala/bot && npm start
Passo a passo completo →

🐧 Linux ou VPS

Para deixar ligado 24 horas num PC antigo, Raspberry Pi ou servidor.

sudo apt install -y nodejs git ffmpeg
git clone https://github.com/ruan2311/opala.git
cd opala/bot && npm start
Passo a passo completo →

🪟 Windows

Instale o Node.js e o Git, e o resto pelo PowerShell.

winget install --id Gyan.FFmpeg -e
winget install --id yt-dlp.yt-dlp -e
git clone https://github.com/ruan2311/opala.git
cd opala\bot; npm start
Passo a passo completo →

🦖 Pterodactyl (Waifly e parecidos)

Hospedagens de bot com painel. Envie a pasta bot em .zip, coloque o ffmpeg e o yt-dlp na pasta bin e use o comando:

sh iniciar.sh
Passo a passo completo →
📱

Use sempre um número secundário. O bot usa o número como se fosse uma pessoa, e o WhatsApp pode banir números que agem como robô. Nunca use o seu número principal.
